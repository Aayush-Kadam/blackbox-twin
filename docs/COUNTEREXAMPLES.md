# Counterexample and refinement usage

All commands operate on explicitly supplied owned local fixtures. No remote adapter or
network target discovery is added. Every output directory must be empty/new. The examples
below are project-relative PowerShell commands after the README installation.

## Complete automatic demonstration

```powershell
.venv/Scripts/python.exe scripts/run_m3_demo.py --out runs/m3 --evaluation-seed 20261027 --count 100
```

This freezes input sequences before initial learning, uses an intentionally small initial
random-W search, generates and executes a twin, discovers and reproduces a mismatch,
deletion-minimizes it, seeds AALpy's observation cache with recorded target outputs, returns
confirmed mismatches through its equivalence-oracle interface, regenerates a twin and
replays every distinct earlier observation. A second search iteration tests the revised
twin. Paired evaluation then runs separately on the untouched frozen set.

The initial one-state hypothesis was learned normally; it was not corrupted. The observed
five-state revision is generated by AALpy's inference procedure, not a hand-edited table.
The default tiny initial search is for this demonstration; it is not a recommended claim
of sufficient testing for arbitrary targets. Model-guided search remains separately available.

## Individual commands

```powershell
.venv/Scripts/bbt.exe loop --target examples/delayed/target.json --out runs/loop --budget 6000 --max-iterations 2 --seed 7
.venv/Scripts/bbt.exe diff --target examples/delayed/target.json --model runs/loop/revisions/000/model.json --strategy guided --guided-depth 5 --candidates 200 --budget 1000 --out runs/diff
.venv/Scripts/bbt.exe counterexample minimize --target examples/delayed/target.json --model runs/loop/revisions/000/model.json --comparison runs/diff/comparison.json --budget 1000 --out runs/minimized
$case = (Get-ChildItem runs/minimized/counterexamples -Recurse -Filter discovery.json | Select-Object -First 1).FullName
.venv/Scripts/bbt.exe counterexample replay --target examples/delayed/target.json --model runs/loop/revisions/001/model.json --case $case --out runs/replay
.venv/Scripts/bbt.exe refine --target examples/delayed/target.json --model runs/loop/revisions/000/model.json --case $case --training-db runs/loop/observations.sqlite --max-iterations 1 --budget 6000 --out runs/refined
```

`refine` requires a matching original model ID on the discovery record and the target ID/
version. It imports the supplied observation DB, preserving and replaying its observed
traces. The example imports accumulated observations from the earlier loop; this is a
reproduction/import example, not a new independent refinement experiment. Earlier corpus
files remain intact. `replay` may use a revised model intentionally, so it checks target
identity but does not require the old model ID to match the replacement.

`diff` writes a versioned `comparison.json` for the first non-agreement. Only behavioral
disagreements are valid minimization inputs. Timeout/crash/reset/unsupported/budget results
stop discovery without becoming learning counterexamples. `counterexample minimize` writes
its attempts and a portable corpus discovery record if a mismatch was actually reproduced.
Its local action/attempt budgets are configurable; every replay also consumes the global
original/twin Session budgets. No symbol/reference repair is guessed.

## Explicit paired evaluation

Freeze this file before executing the learning/refinement commands being evaluated:

```powershell
.venv/Scripts/bbt.exe holdout create --target examples/delayed/target.json --out runs/frozen.json --seed 20261027 --count 100 --min-length 16 --max-length 24
# Execute the loop here, keeping runs/frozen.json out of its inputs.
.venv/Scripts/bbt.exe holdout compare --target examples/delayed/target.json --initial runs/loop/revisions/000/model.json --refined runs/loop/revisions/001/model.json --sequences runs/frozen.json --training-db runs/loop/observations.sqlite --out runs/paired --budget 6000
```

Both models see the same input words, with reset original/twin processes for each word.
Original reference traces are checked for consistency between passes. Overlap with
recorded complete physical training words is rejected; prefix/transition reuse is expected.
The evaluator never supplies outputs to learning. A standalone supplied sequence file is
not automatically proof that its author kept it secret; the demo script enforces the
intended order, and its timestamps/phase records are independently audited.

## Files and stopping rules

- `revisions/NNN/`: preserved model, twin, per-hypothesis checkpoints and revision manifest.
- `counterexamples/UUID/discovery.json`: immutable original/minimized failure, normalized
  and raw JSON, first divergence, strategy/seed, model identity, costs and replay metadata.
- `counterexamples/UUID/outcome-NNN.json`: append-only resolution or incomplete-refinement status.
- `observations.sqlite`: all physical original and twin events, phase labels and artifacts.
- `summary.json`: stop reason, revisions, iterations, regressions, per-phase and cumulative costs.

Stopping conditions include action/reset/time/sequence limits, bounded candidate exhaustion,
max iterations, oracle failures, unsupported contracts, repeated unchanged hypotheses,
the 100-hypothesis guard and failed regression replay. A lack of found counterexamples means
only that this search did not find one. It does not establish equivalence. A successful CLI
execution likewise does not by itself satisfy a milestone gate; inspect the artifacts.

Native exit codes: normal operation 0; behavioral disagreement from `diff`/`replay` 3;
bounded loop stop/failure or unsupported/infrastructure result 2; argument/uncaught errors 1.
Some PowerShell wrappers expose nonzero native exit codes as their own exit 1; inspect
`$LASTEXITCODE` or use a direct subprocess when distinguishing them.
